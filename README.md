# مدينتي | لعبة بناء وإدارة المدن

لعبة بناء مدن عربية ثنائية الأبعاد بمنظور إيزومتري باستخدام Flutter.

- خريطة مدينة قابلة للبناء.
- طرق ومناطق سكنية وتجارية وصناعية.
- محطة كهرباء وحدائق.
- ميزانية وتكاليف وإيرادات وصيانة.
- محاكاة لنمو السكان والمباني والوظائف والسعادة.
- إزالة المباني وإنشاء مدينة جديدة.
- واجهة عربية أفقية لأجهزة Android.

كل تحديث على main يشغّل GitHub Actions لبناء APK. نزّل artifact باسم madinati-city-builder-apk من صفحة Actions.

لعبة أصلية مستوحاة من ألعاب تخطيط المدن، وليست نسخة من Cities: Skylines أو من أصولها التجارية.
