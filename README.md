# مغامرات البطل

لعبة منصات ثنائية الأبعاد أصلية باللغة العربية، مبنية بـ Flutter وDart دون أصول أو شخصيات محمية بحقوق ماريو.

## التشغيل محلياً

1. ثبّت Flutter SDK.
2. من مجلد المشروع نفّذ:
   `flutter create --platforms=android --project-name qahraman_platformer .`
3. ثم:
   `flutter pub get`
4. شغّل:
   `flutter run`

## بناء APK

يوجد GitHub Actions في `.github/workflows/build.yml`. كل تحديث على فرع main يشغّل بناء APK إصدار Release ويحفظه كـ Artifact باسم `qahraman-release-apk`.

## التحكم

- السهمان على اليسار واليمين للحركة.
- زر القفز على اليمين.
- اجمع العملات، تجنب الحفر، واقفز فوق الأعداء.
- أكمل المراحل الثلاث للوصول إلى النهاية.

## المحتوى

- ثلاث مراحل بتدرج في الصعوبة وألوان وبيئات مختلفة.
- رسومات مرسومة برمجياً باستخدام Canvas داخل Flutter.
- لاعب وأعداء وعملات ومنصات وعناصر بيئية أصلية.
