# مدينتي 3D | لعبة بناء وإدارة المدن

لعبة بناء مدن ثلاثية الأبعاد لأجهزة Android باستخدام Flutter ومحرك three_js للرسم ثلاثي الأبعاد داخل التطبيق، دون WebView.

## المزايا
- مشهد مدينة ثلاثي الأبعاد بمنظور كاميرا قابل للدوران والتقريب والإبعاد.
- بناء الطرق والمنازل والمتاجر والمصانع ومحطات الكهرباء والحدائق.
- مبانٍ ثلاثية الأبعاد بارتفاعات ونوافذ وتفاصيل مختلفة.
- ميزانية وسكان ووظائف وسعادة ومحاكاة نمو المدينة.
- إزالة المباني وإنشاء مدينة جديدة.
- واجهة عربية أفقية.

## بناء APK
كل دفع إلى main يشغّل GitHub Actions. نزّل artifact باسم madinati-city-builder-apk من صفحة Actions.

اللعبة أصلية مستوحاة من ألعاب تخطيط المدن، وليست نسخة من Cities: Skylines أو من أصولها التجارية.
