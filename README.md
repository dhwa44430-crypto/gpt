# مغامرات البطل – Anime Platform Adventure

لعبة منصات ثنائية الأبعاد مبنية بمحرك Godot 4.4.1، مهيأة لأجهزة Android بالوضع الأفقي.

## الموجود حالياً
- شخصية أنمي أصلية من sprite sheet بستة إطارات منفصلة للحركة والقفز.
- عوالم مرسومة ومناطق خضراء وصحراء وثلوج.
- حركة يمين ويسار وقفز، مع أزرار لمس.
- عملات وأعداء متحركون وثلاث مراحل.
- كاميرا تتبع اللاعب ونظام قلوب وإعادة المحاولة.

## البناء
GitHub Actions ينزّل صور اللعبة من ملفات المشروع السابقة المحفوظة في تاريخ المستودع، ثم يستوردها Godot ويصدر APK لأندرويد.
