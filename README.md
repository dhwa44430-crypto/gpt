# مغامرات ليث – لعبة منصات 2.5D

لعبة مغامرات جانبية أصلية لأجهزة Android، مبنية باستخدام Flutter وFlame. تستخدم اللعبة رسومات كرتونية كصور PNG مستقلة للشخصية وحركاتها والأعداء والعملات والعناصر والمنصات والخلفيات.

## طريقة اللعب
- التحرك يميناً ويساراً والقفز بأزرار لمس كبيرة.
- جمع العملات وتجاوز الأعداء بالقفز فوقهم.
- منصات مرتفعة ومسارات متعددة ونقطة نهاية للمرحلة.
- ثلاث محاولات قبل انتهاء اللعبة.

## بناء APK
كل دفع إلى main يشغّل GitHub Actions. نزّل ملف APK من artifact باسم layth-adventure-apk في صفحة Actions.

الشخصيات والأصول الفنية أصلية من حزمة Kenney New Platformer Pack المرخصة CC0، وليست نسخاً من شخصيات أو رسومات ألعاب تجارية.
