# Worm Arena

A native Flutter Android snake-arena game inspired by the broad arcade mechanics of snake-eating games.

## Gameplay
- Drag inside the arena to steer the worm.
- Collect glowing food to grow and increase your score.
- Avoid the arena edges and your own body.
- Choose between six original color skins.
- Smooth frame-based movement with custom-drawn game graphics.

## Build
GitHub Actions builds a release APK on pushes to `main` and uploads it as the `worm-arena-android-apk` artifact.

This project uses original Flutter drawing and does not include proprietary Worms Zone assets.
