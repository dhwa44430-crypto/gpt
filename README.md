# Arrow Escape — Flutter

لعبة ألغاز أسهم بأسلوب المتاهة السوداء على خلفية بيضاء، مبنية باستخدام Flutter فقط.

## البناء
يتولى GitHub Actions تثبيت Flutter وتشغيل التحليل وبناء APK تلقائياً عند كل تحديث على main.

## تنزيل APK
من تبويب Actions افتح آخر عملية بناء ناجحة ونزّل artifact باسم arrow-escape-flutter-apk.
