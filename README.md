# محاكي المستشفى | Hospital Simulator

مشروع لعبة Android ثلاثية الأبعاد بمحرك Godot 4.4.1. تبدأ اللعبة من جديد بهيكل نظيف، بمنظور علوي قابل للتحريك والتقريب، وإدارة أقسام المستشفى والمرضى والموظفين والميزانية.

## اللعب
- إدارة مستشفى ثلاثي الأبعاد: استقبال، طوارئ، رقود، عمليات.
- أسرّة وتجهيزات طبية وممرات ومواقف إسعاف.
- استقبال المرضى وعلاجهم، شراء الأسرّة وتوظيف الطاقم.
- نظام أيام وميزانية ودخل.
- تحريك الكاميرا بالسحب والتقريب والتبعيد على الهاتف.
- تحميل نماذج GLB للمستشفى والشخصيات أثناء البناء، مع بدائل آمنة إذا تعذر استيراد نموذج.

## البناء
كل push إلى main يشغّل GitHub Actions. عند نجاح التصدير يظهر artifact باسم hospital-simulator-android.
