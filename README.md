# Arrow Escape Puzzle

لعبة ألغاز أسهم ثنائية الأبعاد لأجهزة Android، مبنية بمحرك Godot 4.4.1.

## طريقة اللعب
- اضغط على السهم ليخرج من اللوحة باتجاه رأسه.
- إذا كان الطريق أمامه مسدوداً، أزل الأسهم التي تعيقه أولاً.
- أكمل اللوحة للانتقال إلى مستوى جديد.
- أزرار التراجع والتلميح وإعادة المستوى متاحة في الأسفل.

## البناء
يبدأ GitHub Actions تلقائياً عند كل تحديث على فرع main، وينشئ APK لأندرويد كـ Artifact.
