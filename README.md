# محاكي المستشفى | Hospital Simulator

لعبة إدارة مستشفى ثلاثية الأبعاد بمحرك Godot 4.4.1، بكاميرا علوية مناسبة للمس على Android.

## النسخة الأولية
- مشهد مستشفى ثلاثي الأبعاد بأقسام الطوارئ والرقود والاستقبال والعمليات.
- أسرّة ومرضى ومكتب استقبال وتجهيزات طبية مجسمة.
- إدارة الميزانية، علاج المرضى، شراء الأسرّة وتوظيف الممرضين.
- الانتقال بين الأيام وحساب دخل المستشفى.
- تحريك الكاميرا بالسحب والتقريب والتبعيد.

## بناء Android
كل تحديث على فرع main يشغّل GitHub Actions. عند نجاح البناء يظهر artifact باسم hospital-simulator-android في صفحة Actions.

المشروع يستخدم Godot 4.4.1 وواجهة رسومية 3D مولّدة من Meshes داخل المحرك في هذه النسخة الأولية؛ ليست بعدُ حزمة نماذج بشرية أو أثاث واقعي عالي التفاصيل.
